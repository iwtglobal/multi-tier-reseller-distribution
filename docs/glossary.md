# Glossary — Multi-Tier Reseller Distribution

| Term | Definition |
|------|------------|
| **Commission / margin** | Reseller earnings on sell-through, configured by product and tier |
| **Dealer / sub-distributor** | Mid-tier node that funds retail agents from master float |
| **Float** | Prepaid credit or working capital a reseller uses to buy/sell digital value |
| **Hierarchy** | Parent/child tree of resellers under an operator or brand |
| **Leaf / retail agent** | End-selling node with POS that serves customers |
| **Master distributor** | Top partner tier under the operator root |
| **Stock transfer** | Moving voucher inventory or float from parent to child |
| **Sell-through** | Sales recorded at leaf that consume float/stock |
| **Void / clawback** | Reversal of a sale that may reverse commission |
